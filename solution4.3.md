I created a student marksheet table displaying marks of five students in three subjects. I built the table using <table>, <tr> for rows, <th> for header cells, and <td> for data cells. I organized the table structure into <thead> for the header rows, <tbody> for the main student data, and <tfoot> for the summary. I gave a title to the table using the <caption> tag. To show total and average marks for each student and to display the class average, I used the footer section <tfoot>. I implemented colspan to merge three subject columns under one main heading "Subjects" and rowspan to merge Roll No, Student Name, Total, and Average headers across two rows, making the table more structured and readable. I also used colspan="7" in the last footer row to show the final result summary. I ensured all table headers were meaningful and added border and cellpadding for better visibility.
